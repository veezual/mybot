# V108 — фикс Camoufox, шторма прогрева и честности прогнозов

Дата: 29.10.2026. База: твоя V106/V107. Меняются ТОЛЬКО 5 файлов, база и .env не трогаются.

## Что сломалось (по твоим логам от 01:23–01:27)

1. **`odds followup: Failed to launch the browser process`**
   Сбор кефов (Винлайн) запускал ВТОРОЙ Camoufox на том же профиле `hltv_profile`,
   пока синглтон жив. Firefox-профиль можно занять только одному процессу —
   второй вылетает с `exitCode=0`. Это падение было ГАРАНТИРОВАННЫМ, каждый раз.

2. **`Фоновый HLTV-сбор: Failed to launch...` (дважды подряд)**
   Когда синглтон умер, код бросал мёртвый контекст НЕ закрыв его. Зомби-процесс
   продолжал держать профиль → все повторные запуски вылетали. Паузы между
   попытками не было — задачи штурмовали запуск друг за другом.

3. **Шторм прогрева**: «Прогрев: 10 команд» → 10 ошибок → и так 4 раза за 90 секунд.
   Неудачные прогревы не запоминались: каждый клик по кнопке заново долбил
   bo3.gg по тем же MAYBE/Prestige/Revenge/...

4. **Карточка Leo vs MAYBE «Без явного фаворита»** выглядела как настоящий прогноз,
   хотя по командам вообще нет данных (пустота, а не равенство сил).

## Что исправлено

| Файл | Правка |
|------|--------|
| `collector.py` | Кефы браузерных БК ходят через общий синглтон (второй браузер убран); мёртвый экземпляр корректно закрывается перед перезапуском; после неудачного запуска 60 сек тишины; прогрев не дёргает команды/пары, которые недавно не ответили (кулдаун 30 мин); полный прогрев не чаще раза в 2 мин; если браузерные БК упали — кефы Пари (HTTP) всё равно сохраняются |
| `bot.py` | Фоновая HLTV-сверка не чаще раза в 5 минут (раньше каждый клик = полный цикл 403→Camoufox→минута впустую) |
| `predict.py` | «Недостаточно данных» вместо фейкового 50/50 на пустоте; данные только по одной стороне → уверенность жёстко ограничена 58%; H2H-одиночка без карт/формы больше не даёт 87% |
| `value_model.py` | VALUE-сигналы не создаются по матчам с неполными данными |
| `config.py` | Новые настройки: `WARMUP_FAIL_COOLDOWN=1800`, `WARMUP_MIN_INTERVAL=120`, `BG_HLTV_MIN_INTERVAL=300`, `PREDICT_CONF_CAP_LOWDATA=58` — можно крутить в одном месте |

## Как поставить

1. Останови бота (Ctrl+C в окне запуска).
2. Скопируй 5 файлов из этого архива в папку бота
   (`...\cs2_analytics_bot_V106\`) с заменой.
3. Запусти `run_bot.bat` как обычно.

База `cs2_bot.db` совместима, миграции не нужны, откат = вернуть старые файлы
из бэкапа.

## Если Camoufox ПОСЛЕ фикса всё равно не запускается

Значит профиль побился (это бывало после жёстких убийств процесса). Лечение:
остановить бота, удалить папку `hltv_profile` внутри папки бота — она создастся
заново с чистыми куками (придётся один раз пройти проверку Cloudflare).

## Что изменишь на глаз после обновления

- В логах исчезнут повторные «Прогрев: 10 команд» каждые 20 секунд — теперь
  одна неудачная команда долбится не чаще раза в 30 минут.
- «odds followup: Failed to launch» больше не появится: Винлайн ходит через
  общий браузер.
- Карточки матчей без данных честно скажут «Недостаточно данных», а уверенность
  на полуданных не будет выше 58%.
- Фоновая HLTV-сверка — раз в 5 минут, а не на каждый клик.

## Что осталось в бэклоге (следующие шаги)

1. Линковка формы между неймспейсами ID (b20832 ↔ 13286 FUT) — для топ-матчей
   с HLTV-сопоставлением форма из bo3.gg сейчас теряется.
2. Калибровка уверенности по истории `value_signals` (Brier score) — после
   того как наберётся 30–50 закрытых сигналов.
3. Поправка на силу соперников в винрейтах карт (побеждать tier-3 в 70% —
   не то же самое, что Vitality).
