# CS2 Analytics Bot — V109 (AI-аналитик + живой монитор ростеров)

Telegram-бот с умной аналитикой матчей CS2: прогнозы с объяснением,
статистика карт команд, личные встречи (H2H) и коэффициенты русских БК —
всё в виде красивых карточек. С V109 рядом со статистикой работает
бесплатный AI-аналитик и живой монитор смен ростеров.

## Что нового в V109

**1. AI-аналитик (бесплатный, по API-ключу).** Новые кнопки «🤖 AI-разбор»
и «📰 Новости», плюс кнопка 🧠 прямо на карточке прогноза. AI получает
ТОЛЬКО факты из базы (карты с размером выборки, форма, H2H, кефы,
смена ростера, вердикт модели) и интерпретирует их — без выдумок.
Работает с любым OpenAI-совместимым API: Groq (рекомендуется, самый
быстрый и бесплатный — ключ за 2 минуты на console.groq.com/keys),
Google Gemini (aistudio.google.com/apikey), OpenRouter. Ключ вписывается
в .env (AI_API_KEY), инструкция — в боте по команде /aihelp.
Без ключа всё работает по-старому: AI — опциональная надстройка.
Ответы кэшируются на 15 минут: повторный разбор той же пары — мгновенный
и без расхода лимита.

**2. Живой монитор ростеров.** Раз в 4 часа бот сверяет составы команд
матчей дня с PandaScore (HTTP, без браузера). Обнаружил замену — в
прогнозе появляется «⚠️ СМЕНА РОСТЕРА: у X 2 дн. назад менялся состав
(ушли…, пришли…)», уверенность урезается до 65% (статистика набрана
старым составом), а value-скан блокирует ставки по этой паре.

**3. Байесовский шринкейдж карт.** bo3.gg теперь отдаёт не только
винрейт карты, но и число карт в выборке (n). «Cache 100%» после двух
игр превращается в честные 70%: (100*2 + 50*3)/5 — винрейт каждой карты
подтягивается к 50% с весом MAP_SHRINK_PRIOR=3. Карта на 20 матчей
почти не меняется, шум двух партий больше не решает прогноз.

**4. Новости команд без ключей.** Кнопка «📰 Новости» ищет свежие
новости команды через бесплатный поиск DuckDuckGo (пакет ddgs) и с
помощью AI делает короткую сводку: что случилось и как влияет на матч.
Без AI-ключа — просто список найденных заголовков.

**5. Быстрый отклик.** AI-ответы кэшируются; сбор фактов для AI идёт
только из базы (без сети); ростер-монитор и все тяжёлые сборы —
строго фоновые; без ключа AI-кнопка мгновенно отдаёт разбор из базы.

Обновление с V106-V108: скопировать ВСЕ *.py и .env поверх старой папки
(либо .env не копировать, а дописать в свой секцию AI из нового .env).
Схема БД меняется мягко: новые таблицы team_rosters/roster_alerts и
колонка team_maps.games создаются сами при первом запуске, старые
данные не трогаются. Пакет новостей: pip install ddgs.

## Что нового в V107/V108 — «модель больше не спорит с рынком вслепую»

Кейс V106: на FUT vs Nemiga бот выдал «Nemiga — уверенность 80%» при кефах
1.32/3.40 (рынок давал Nemiga ~28%). Разбор показал 4 причины, все закрыты:

**1. Форма команд больше не теряется.** Раньше при свежих картах форма
вообще не запрашивалась (`ensure_match_data`), а сохранённая под чужим id
(b20832 вместо 13286) не находилась. Теперь форма собирается отдельно и
читается через алиасы id (`get_form_any`/`get_maps_any`/`get_h2h_any`).

**2. Карты вне активного пула не влияют на прогноз.** С 08.07.2026 Active
Duty: Ancient, Anubis, Cache, Dust2, Inferno, Mirage, Nuke — винрейты
Overpass/Train больше не качают силу (см. `config.ACTIVE_DUTY_MAPS`).
Плюс карта учитывается только при ≥3 сыгранных матчах (`MIN_MAP_GAMES`).

**3. Санити-чек против рынка.** Если модель расходится с линией БК сильнее
15 п.п. (`PREDICT_MAX_DIVERGENCE`), уверенность урезается до 62% и в карточке
появляется «⚠️ РАСХОЖДЕНИЕ С РЫНКОМ» вместо бодрого VALUE.

**4. Value-скан защищён от сломанной модели.** Сигналы с расхождением
модель/рынок ≥20 п.п. блокируются с объяснением; ставка по сигналу никогда
не превышает 2% банка (`VALUE_MAX_STAKE_PCT`), даже если ¼ Келли требует
больше. Мелочь: исправлен баг «Риск: слабейшая карта» (всегда считалась
у team1) и defensive-разбор формы bo3.gg (3 формата ответа).

V108 (стабильность): ВСЕ браузерные задачи ходят через один Camoufox-
синглтон (исправлен краш «Failed to launch the browser process» из-за
двух браузеров на одном профиле); после неудачного запуска браузера —
минута тишины вместо шторма; прогрев не долбит команды, по которым
источник недавно не ответил; фоновая HLTV-сверка не чаще раза в 5 минут;
пустые данные больше не маскируются под «Без явного фаворита» (потолок
уверенности 58% при однобоких данных, честное «Недостаточно данных»
на пустоте).

Установка: скопировать `*.py` поверх старой папки (`.env`, базу и venv не
трогать) — схема БД не меняется, данные дообновятся сами по TTL.

## Предыдущие версии


## Что нового в V106 — «Эпоха bo3.gg»

**1. Карты команд и H2H теперь приходят за 2–5 секунд вместо 1,5–4 минут.**
Найден открытый источник — сайт bo3.gg (CS2-статистика, ключи не нужны):
история матчей каждой команды с картами за 6 месяцев + личные встречи.
Запросы идут параллельно по HTTP, браузер не открывается вообще.
Camoufox остаётся запасным путём, если bo3.gg недоступен.

**2. Прогрев фоном.** После загрузки списка матчей бот сам, тихо, собирает
карты ВСЕХ команд дня (по одной, с паузами). К моменту твоего клика всё
уже в кэше — прогноз приходит мгновенно.

**3. Прогноз работает даже без HLTV-ID.** Матчи, не сопоставившиеся с HLTV
(раньше был алерт «открой список через минуту»), теперь прогнозируются
по именам команд через bo3.gg.

**4. Починено (корневые причины из твоего лога):**
- `too many values to unpack (expected 2)` / `not enough values...` — база
  данных принимала карты только списком пар; словарь молча ломал сохранение,
  поэтому карты «собирались, но не сохранялись». Теперь формат любой;
- `database is locked` — SQLite ждёт очереди до 15 секунд вместо мгновенного
  отказа (WAL + busy_timeout);
- `query is too old` (падение обработчика кнопки) — ответ клику уходит
  мгновенно, все поздние ответы через защиту (фикс V105.1 включён).

**5. Диагностика:** `test_datasources.bat` теперь проверяет и bo3.gg (пункт 5).

## Обновление с V103/V104

1. Распакуй папку V105 рядом со старой.
2. `.env` в комплекте уже с твоими токенами (бот и ключи источников) —
   отдельно копировать ничего не нужно.
3. Venv создавать заново не нужно: скопируй файлы `*.py` из V105 в старую
   папку поверх (venv и `hltv_profile` остаются), но **добавь 2 зависимости**:
   запусти `install_bot.bat` один раз (он доустановит aiohttp и rapidfuzz)
   или в консоли: `venv\Scripts\pip install -r requirements.txt`.
4. Запусти `run_bot.bat`. Таблица entity_map и колонка турнира создадутся сами.

## Установка с нуля (Windows)

1. Установи Python 3.12 с [python.org](https://www.python.org/downloads/) (галочка *Add to PATH*).
2. Распакуй папку бота, запусти **`install_bot.bat`** (создаст venv, поставит зависимости, скачает браузер Camoufox ~1.5 ГБ).
3. Запусти **`run_bot.bat`**.
4. В Telegram: `/start` → жми кнопки.

## Важно

- При первом HLTV-сборе откроется **видимый браузер Firefox** — это нормально. Ничего не нажимай в окне, просто жди.
- Если Cloudflare закрутил «Just a moment» дольше минуты — нажми кнопку ещё раз (куки уже в профиле `hltv_profile`).
- Для сервера/фона: в `.env` поставь `HEADLESS=true`.
- API-Sport в тестовом плане даёт **100 запросов/сутки на ключ** — бот тратит его бережно (только как резерв). Смотри остаток: `test_datasources.bat`.

## Структура

```
config.py           — настройки, пути, TTL, список БК, ключи источников
database.py         — SQLite: teams, team_maps, matches, h2h, odds, value_signals, entity_map
hltv_api.py         — парсеры HLTV (матчи, карты, H2H)
odds_api.py         — кефы БК: Пари/Фонбет (HTTP JSON) + Винлайн/Бетбум (Camoufox DOM)
sportsdata.py       — V105: PandaScore + API-Sport (ротация), мэтчинг, единый формат, лайв
collector.py        — сбор по требованию: быстрый путь + HLTV + кефы, блокировки
predict.py          — прогноз + имплайд-вероятности рынка + детектор value
value_model.py      — value-скан, сигналы, история (флэт/Келли)
cards.py            — генерация PNG-карточек (Pillow)
bot.py              — aiogram 3: меню, хэндлеры, лайв, карточки в чат
test_odds.py        — диагностика кефов БК на твоей машине
test_datasources.py — диагностика PandaScore / API-Sport / мэтчинга
```
