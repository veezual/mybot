ПОЧЕМУ У ТЕБЯ ПАДАЛ БОТ
-----------------------
На скриншоте ошибка: AttributeError: module 'database' has no
attribute 'get_form_any' (bot.py, строка 669).

Причина: в прошлый раз ты заменил ТОЛЬКО bot.py на новую версию,
а database.py остался старым. Новые bot.py и database.py — ПАРА,
они должны быть одной версии. V109 решает это раз и навсегда:
ниже — обновление ВСЕХ файлов разом.

КАК ОБНОВИТЬСЯ (2 минуты)
-------------------------
Вариант А (рекомендую): замени ВСЕ *.py и .env в своей папке
  1. Останови бота (Ctrl+C в окне, где он запущен).
  2. Скопируй из этого архива в свою папку D:\cs2_analytics_bot...\ :
     ВСЕ файлы .py (их 17), .env, requirements.txt, README.md.
  3. Файлы НЕ трогаем: cs2_bot.db (твоя база), папку hltv_profile,
     run_bot.bat — они подхватятся сами.
  4. Поставь новый пакет для новостей (одна команда):
        pip install ddgs
  5. Запусти run_bot.bat. Готово: новые таблицы в базе создадутся сами.

Вариант Б (полная замена папки): распакуй архив целиком рядом, замени
  в .env свой TG_TOKEN/ALLOWED_USER_ID (они уже внутри, но сверь),
  скопируй свою cs2_bot.db и hltv_profile в новую папку.

КАК ВКЛЮЧИТЬ AI-АНАЛИТИКА (бесплатно, 2 минуты)
-----------------------------------------------
Вариант 1 — GROQ (рекомендую: без карты, самый быстрый отклик):
  1. Зайди на сайт:  https://console.groq.com/keys
     (регистрация по почте или Google-аккаунту)
  2. Нажми «Create API Key», скопируй ключ (начинается с gsk_...).
  3. Открой .env, найди строку AI_API_KEY= и вставь ключ:
        AI_API_KEY=gsk_твой_ключ
     (AI_API_BASE и AI_MODEL уже прописаны под Groq — не трогай)
  4. Сохрани .env и перезапусти бота.

Вариант 2 — GOOGLE GEMINI (AI Studio):
  1. Сайт:  https://aistudio.google.com/apikey  ->  Create API key
  2. В .env: закомментируй три строки Groq-блока (# в начале) и
     раскомментируй Gemini-блок, вставив свой ключ:
        AI_API_KEY=твой_google_ключ
        AI_API_BASE=https://generativelanguage.googleapis.com/v1beta/openai
        AI_MODEL=gemini-2.5-flash
  3. Перезапусти бота.

Вариант 3 — OPENROUTER (много бесплатных моделей):
  1. Сайт:  https://openrouter.ai/keys
  2. AI_API_BASE=https://openrouter.ai/api/v1

Проверка: напиши боту команду /aihelp — он покажет, видит ли ключ.
Без ключа бот работает как раньше — AI это опциональная надстройка.

  карточке прогноза. AI получает ТОЛЬКО факты из твоей базы (карты

  с PandaScore. Смена игрока -> предупреждение в прогнозе + потолок

  (винрейты с малой выборкой сглаживаются к 50%).
